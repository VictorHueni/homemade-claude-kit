# Subagents

- Driving a plan increment by increment: in a terminal use `ralph.sh`; when no terminal is available (mobile, remote, cloud), one subagent per increment, following the `agent-ralph-loop` skill's `references/chat-orchestration.md` (in the plugin cache: `~/.claude/plugins/cache/*/agent-loop/<newest>/skills/agent-ralph-loop/references/`).
- Fan-out audits split by directory: after the slices return, grep every src symbol a slice called dead across the whole test tree yourself, and size the test files that exist only to exercise it; the dead code and its sole test usually land in different slices. Record the joined leads in the consolidated report.
