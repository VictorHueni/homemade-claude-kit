**OKF v0.1 baseline — artefact frontmatter becomes a superset of Google's Open Knowledge Format (clew ADR pending, 2026-07-01):**
Adopted [Open Knowledge Format (OKF) v0.1](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md) (Google Cloud, 2026-06-12) as the interchange baseline for the artefacts the kit **generates** (`docs/**`); the kit itself (`skills/`+`rules/`) is out of scope for now (issue [#53](https://github.com/VictorHueni/homemade-claude-kit/issues/53)). The universal artefact frontmatter block is now an OKF **superset**: the six OKF fields (`type` — required — `title`, `description`, `resource` (omit when no external asset), `tags`, `timestamp`) precede the existing kit lifecycle fields (`status`, `owner`, `last_reviewed`, `review_interval`, `supersedes`/`superseded_by`), which remain valid OKF **extension** fields (OKF forbids consumers rejecting unknown fields — **no existing field migrated or renamed**). `type:` carries a **human-readable OKF display name** (Title Case — OKF idiom, `type` doubles as the presentation label), defined canonically in the registry's `okf_type` mapping (not LLM-inferred, not snake_case); the snake_case `type` column stays the internal key. OKF **reserved files** adopted: `index.md` (lowercase, frontmatter-free progressive-disclosure listing; root `docs/index.md` carries only `okf_version: "0.1"`) and `log.md` — the old frontmatter-bearing uppercase `INDEX.md` nav hub migrates `git mv INDEX.md index.md` + frontmatter strip (content moves to body). **Collection-type explosion** (one file per minted ID) deferred (issue [#54](https://github.com/VictorHueni/homemade-claude-kit/issues/54)). **No artefact step / ID / DAG / ER / artefact-count change** — this is a cross-cutting *frontmatter-schema* change, so it runs the `skill-creation-sync.md` blast radius but mints nothing. **Foundation (commit 1):** `rules/artefact-frontmatter.md` (rewritten — OKF superset schema + reserved-file convention + INDEX→index migration note) · `rules/artefact-types-registry.md` (OKF `type` source note + canonical `okf_type` display-name mapping) · this entry · open items [#53](https://github.com/VictorHueni/homemade-claude-kit/issues/53) + [#54](https://github.com/VictorHueni/homemade-claude-kit/issues/54) filed · analysis at `var/reports/okf-compliance/`. **Layer 1 — tooling & convention (commit 2):** `util-metamodel-audit` Check 17 (require non-empty `type`, OKF-recommended-field warnings, validate the `okf_type` enum, reserved-file exemption for `index.md`/`log.md`, root-`index.md` `okf_version` check) · `util-metamodel-scaffold` (emit frontmatter-free `index.md` + root `okf_version`; index-template, SKILL, methodology rewritten) · `util-metamodel-migration` (`okf-index-rename` + `okf-frontmatter-upgrade` rows, `INDEX.md` detection signal) · `INDEX.md`→`index.md` sweep (`rules/metamodel.md` incl. canonical tree, `README.md`, `agent-config/**`, `discovery-idea` incl. frontmatter-free ideation index) · `rules/skill-creation-sync.md` + `util-metamodel-audit` methodology (OKF-superset wording). **Layer 2 — producers (commit 3):** serialised the OKF fields into the minting-skill frontmatter. Uniform prose enumeration updated across 25 SKILLs (the `(title, status, …)` list → OKF-superset, `type` sourced from the registry's `okf_type`, DRY — no per-skill hardcoding). Literal output blocks filled: `discovery-idea` (Idea), `spec-use-case` ×3 (Use Case; its `index.md` template made frontmatter-free as an OKF reserved index), `arch-adr` ×3 (Architecture Decision Record; SKILL + both MADR templates), `dev-stack-guide` ×2 + `dev-getting-started` (Stack Guide / Getting Started Guide), `ux-design-system` wording (Design System). **Registry gained 7 supporting doc-type rows** (`runbook`, `bug_rca`, `stack_guide`, `getting_started`, `research_note`, `workshop_note`, `design_system` — all mint no ID) so every doc producer resolves a `type`; Check 17 `okf_type` enum extended to match. **arc42 (KISS, commit 4):** all 8 arc42 section templates (`arch-arc42` ×5 + `arch-c4` ×3) filled with the single umbrella `type: Architecture Documentation` (registry key `arc42_section`, minted by `arch-arc42`); okf_type mapping = Check 17 enum = 39; issue [#55](https://github.com/VictorHueni/homemade-claude-kit/issues/55) closed. **Index freshness (commit 5):** because `index.md` is frontmatter-free it dropped out of the `review_interval` staleness check, so Check 17 gained a **stale-index** sub-check — an `index.md` is flagged (Warning) when any artefact in its subtree has a newer git-commit time, restoring the drift signal the old frontmatter'd `INDEX.md` had. **Still pending:** mint the clew ADR (metamodel SoT per clew ADR-0008). Shipped via PR [#56](https://github.com/VictorHueni/homemade-claude-kit/pull/56).
